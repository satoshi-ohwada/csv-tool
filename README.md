# 📊 CSV編集ツール (CSV Editor Web)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Pure JavaScript](https://img.shields.io/badge/Language-Vanilla%20JavaScript-yellow.svg)](https://developer.mozilla.org/ja/docs/Web/JavaScript)
[![Tabulator](https://img.shields.io/badge/Grid-Tabulator%205.x-green.svg)](https://tabulator.info/)
[![PapaParse](https://img.shields.io/badge/Parser-PapaParse-orange.svg)](https://www.papaparse.com/)

ブラウザ上で軽快に動作する、**Microsoft Excel ライクな操作感のタブ式 CSV/TSV エディタ**です。  
ローカル環境・ブラウザ内ですべての処理が完結するため、機密データや個人情報を含むファイルも外部サーバーに送信されることなく、安心・安全に編集できます。

---

## 🌟 主な特徴

### 1. Excel 完全互換の操作感
- **2段ヘッダー表示**: 上段に `A`, `B`, `C`… の座標バー（クリックで昇順・降順ソート切替）、下段に列名（変数名）を表示。26列を超えた場合も `AA`, `AB`… とExcel完全互換の26進数表記で自動拡張。
- **直感的なセル・範囲選択**: マウスドラッグまたは `Shift + クリック / 矢印キー` で矩形範囲を選択可能。
- **双方向コピペ対応**: Excel や Google スプレッドシートとの間で、セル単体および複数行・複数列の矩形範囲をそのままコピー＆ペースト（TSV形式）できます。
- **データ型に応じた自動配置**: 数値データは右寄せ、文字列データは左寄せで自然に表示。
- **ステータスバー集計**: 選択した範囲の「平均」「個数」「合計」を画面下部にリアルタイム表示。

### 2. 強力な検索 & 絞り込み（フィルター）
- **テーブル全体クイック検索**:
  - **AND 検索**: スペース区切り（`東京 営業`）または単語 `and`（`東京 and 営業`）
  - **OR 検索**: 単語 `or`（`ノート or デスクトップ`）、カンマ（`ノート, デスクトップ`）、読点（`、`）、正規表現パイプ（`|`）
  - **列指定検索**: `商品名:ノート` や `部署:営業 and 役職:主任`
  - **数値条件**: `単価:>=100000`, `100..200`, `100以上`
  - **複合論理検索**: `所在地:東京 担当:営業 or 所在地:大阪 担当:開発`
- **列ごとのオートフィルター**:
  - 各列ヘッダーの漏斗アイコンから、Excel風のユニーク値一覧（チェックボックス）で絞り込み。
  - フィルター内検索窓での `or` / `and` / 数値条件による自動チェック対応。
  - 複数列フィルター時の適用順序バッジ表示。

### 3. Excel 完全互換スマートソート (`excelSmartSorter`)
- **カンマ付き数値の正確な比較**: `1,200`、`128,000`、`300` 等の3桁カンマ区切り数値や通貨記号（`¥`, `$`）、パーセント（`%`）を正しく数値として昇順・降順ソート。
- **自然順ソート (Natural Sort)**: 「第1回」「第2回」「第10回」のように文字列内の数値を人間にとって直感的な順序で並べ替え。
- **空白セルの末尾配置**: Excel と同様に、昇順・降順のどちらであっても空白セルは常にリストの末尾に移動。

### 4. 文字コード & 区切り文字の柔軟なサポート
- **エンコーディング自動判別**:
  - **Shift-JIS (CP932)**、**UTF-8 (BOM付き/なし)**、**EUC-JP** を読み込み時に自動検出。
  - 画面上部のセレクトボックスからいつでも文字コードの再解釈・変換保存が可能。
- **区切り文字 & 改行コード**:
  - カンマ (CSV)、タブ (TSV)、セミコロン (;) に対応。
  - 改行コード（CRLF / LF）の指定保存が可能。

### 5. データ整形・クレンジング
ツールバーの「データ整形」メニューから、表全体のデータをワンクリックで一括変換できます。
- **行と列の入れ替え (転置: Transpose)**: 表全体の行と列をワンクリックで瞬時に入れ替え。再度実行すると元の状態に完全復元（インボリューション対応）。
- **セル内の改行を削除**: セル値の中に含まれる改行コード（`CRLF`, `LF`, `CR`）を一括削除。住所や複数行テキストのクレンジングに最適。
- **3桁カンマの着脱**: 数値のカンマ一括付与（`1234` → `1,234`）/ 一括除去（`1,234` → `1234`）
- **空白除去 (TRIM)**: セル前後の余分な半角・全角スペースを除去
- **全角・半角変換**: 全角英数 ⇔ 半角英数、半角カナ → 全角カナ
- **大文字・小文字変換**: `ABC` ⇔ `abc`

### 6. マルチタブ & 快適な編集操作
- 複数ファイルを同時に開いてタブで切り替え可能。
- ファイルのドラッグ＆ドロップによる読み込み。
- **アンドゥ / リドゥ (Ctrl+Z / Ctrl+Y)** 対応。
- 列・行の自由な追加・削除（誤操作を防ぐ事前確認ダイアログ & 最低1行・1列の安全保護付き）、列名変更、列幅の自動調整。

## 🚀 クイックスタート

### 方法 1: ローカルサーバーで起動 (推奨)

Python がインストールされている環境であれば、1行で起動できます。

```bash
# リポジトリディレクトリに移動
cd /path/to/csv-plus-web

# サーバー起動 (ポート 8765)
python3 -m http.server 8765 --bind 127.0.0.1
```

ブラウザで [http://localhost:8765/](http://localhost:8765/) を開きます。

### 方法 2: 起動スクリプトの利用 (Linux / ChromeOS)

```bash
./launch.sh
```

## ⌨️ 主なショートカットキー

| ショートカット | 動作 |
| :--- | :--- |
| **Ctrl + S** | ファイルを保存（上書きまたは別名保存ダイアログ） |
| **Ctrl + Z** | 元に戻す (Undo) |
| **Ctrl + Y** | やり直す (Redo) |
| **Ctrl + F** / **Ctrl + H** | 検索と置換モーダルを開く |
| **ダブルクリック** / **F2** | セルの入力・編集開始 |
| **Enter** | 編集を確定して下のセルへ移動 |
| **Tab** | 編集を確定して右のセルへ移動 |
| **Esc** | セル編集をキャンセル（元の値に戻す） / モーダルを閉じる |
| **矢印キー** | アクティブセルの移動 |
| **Shift + 矢印キー** | 範囲選択の拡張 |
| **Shift + クリック** | 起点セルからクリックしたセルまでを範囲選択 |
| **Ctrl + C** | 選択範囲を TSV 形式でクリップボードにコピー |
| **Ctrl + V** | クリップボードのデータをアクティブセル起点に貼り付け |

## 🔍 検索クエリの記法例

クイック検索バーでは、以下のような多彩な検索構文が利用可能です。

| 検索パターン | 入力例 | 説明 |
| :--- | :--- | :--- |
| **AND 検索** | `東京 営業`<br>`東京 and 営業` | 「東京」と「営業」の両方を含む行 |
| **OR 検索** | `ノート or デスクトップ`<br>`ノート, デスクトップ`<br>`ノート\|デスクトップ` | いずれかの単語を含む行 |
| **列指定検索** | `商品名:ノート`<br>`所在地:東京` | 指定した列名に含まれるデータを検索 |
| **数値比較** | `単価:>=100000`<br>`単価:100..500` | 数値の以上・以下・範囲指定 |
| **複合検索** | `東京 営業 or 大阪 開発` | 「東京 かつ 営業」または「大阪 かつ 開発」を満たす行 |

## 🛠️ 技術スタック & 構成

- **HTML5 / CSS3 / Vanilla JavaScript**: 外部フレームワークに依存しない軽量・高レスポンス設計
- **[Tabulator 5.5](https://tabulator.info/)**: 仮想スクロール（Virtual DOM）による大量データの高速レンダリング
- **[PapaParse](https://www.papaparse.com/)**: 高速で高機能なブラウザ内 CSV/TSV パーサー
- **[Encoding.js](https://github.com/polygonplanet/encoding.js/)**: 高精度な文字コード自動判別および変換処理

## 🔒 プライバシー & セキュリティ

本ツールは**完全クライアントサイド（ブラウザ内）**で動作します。  
読み込んだ CSV/TSV データが外部のクラウドサーバーや解析サービスに送信されることは一切ありません。オフライン環境でも安心してご利用いただけます。
