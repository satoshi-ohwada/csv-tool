# サンプルデータ一覧

動作確認・テスト用の各種CSV/TSVサンプルファイルです。

| ファイル名 | 文字コード | 形式 | 特徴・検証用途 |
| :--- | :--- | :--- | :--- |
| `test_comma.csv` | UTF-8 | CSV (カンマ) | 3桁カンマ付き数値（`1,200` や `128,000`）、空値、日付、文字列が混在するデータ。スマートソートやカンマ着脱の検証用。 |
| `test_sample.tsv` | UTF-8 | TSV (タブ区切り) | タブ区切り形式のデータ。TSV 自動判別の検証用。 |
| `test_sjis.csv` | Shift-JIS | CSV (カンマ) | 日本語 Shift-JIS (CP932) エンコードのデータ。文字コード自動判別の検証用。 |
| `test_sjis2.csv` | Shift-JIS | CSV (カンマ) | Shift-JIS で保存された部署・社員一覧データ。 |
| `test_utf8.csv` | UTF-8 | CSV (カンマ) | UTF-8 で保存された標準的なサンプルデータ。 |
